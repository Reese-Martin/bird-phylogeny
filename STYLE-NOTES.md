# Everybird visual reference

The restyling references Everybird at revision [`f15bc1256ca1bd7a435d63c90c39992d27957ca4`](https://github.com/yusuftaleb/everybird/tree/f15bc1256ca1bd7a435d63c90c39992d27957ca4), specifically [`DESIGN.md`](https://github.com/yusuftaleb/everybird/blob/f15bc1256ca1bd7a435d63c90c39992d27957ca4/DESIGN.md), [`tokens.css`](https://github.com/yusuftaleb/everybird/blob/f15bc1256ca1bd7a435d63c90c39992d27957ca4/src/styles/tokens.css), and [`globals.css`](https://github.com/yusuftaleb/everybird/blob/f15bc1256ca1bd7a435d63c90c39992d27957ca4/src/styles/globals.css).

Light appearance uses the reference's warm paper (`#f6f4ef`), near-black ink (`#1e1e24`), restrained deep-red accent (`#92140c`), muted text (`#5f5f69`), field outline (`#857f74`), hairline (`#dedad2`) and surface (`#ebe8e1`). The UI uses flat dividers, filled quiet controls, rounded corners and a mix of serif headings, sans-serif text and monospace metadata. Shadows are reserved for floating cards, menus and dialogs. Taxonomic selections sit in a compact control dock above the tree.

**Fraunces** semibold gives the wordmark and major titles a field-guide feel. **Source Sans 3** sets the controls, species text and canvas labels, with a true italic for scientific names. **Geist Mono** serves small metadata labels. The fonts are bundled locally under **SIL Open Font License 1.1**.

Font source URLs, sizes and SHA-256 hashes are recorded in [`public/fonts/sources.json`](public/fonts/sources.json). The bundled license notices are [`OFL-Fraunces.txt`](public/fonts/OFL-Fraunces.txt), [`OFL-Source-Sans-3.txt`](public/fonts/OFL-Source-Sans-3.txt) and [`OFL-Geist-Mono.txt`](public/fonts/OFL-Geist-Mono.txt). The webfonts come from official Google Fonts delivery.

The styles are a project-specific implementation inspired by the reference, rather than copied Everybird component CSS. Typography and colors remain local assets for the browser-only privacy contract.

## Dark appearance

Dark appearance is a phyloBirds extension of that visual language, not a claim that the pinned Everybird reference specifies this palette. It uses charcoal paper (`#17191c`), a slightly raised surface (`#22262b`), warm light ink/recorded branches (`#ecebe7`), muted text (`#b0b5bd`), field outlines (`#8b939e`), hairlines/date rings (`#353a41`) and a warm coral accent (`#ef9a85`). Background ancestry uses a separate subdued canvas color (`#454b54`). CSS variables cover page controls, dialogs, country-map land/water/selection and native `color-scheme`; [visual-theme.ts](<src/tree/visual-theme.ts>) supplies matching light/dark canvas palettes. Sticker pixels retain their original colors and transparency; no image inversion or whole-scene color filter is used.

The header's Sun/Moon button makes an explicit Light/Dark choice. Default **System** appearance follows `prefers-color-scheme`; **Use system theme** in the collection's `•••` menu restores it. [theme.ts](<src/theme.ts>) stores only the appearance string under `birds-and-trees-theme` in localStorage, resolves OS changes while System is selected, and follows cross-tab preference changes. Blocked storage leaves a working session choice. [index.html](<index.html>) applies the saved/system appearance and critical background before React paints, including the browser theme-color metadata.

Both canvases redraw their existing geometry when appearance changes. Theme is excluded from MDS/packing identities and geometry dependencies, so it must not refit the map, move its camera or reload every illustration. PNG scenes and their captions/footers use the selected palette; export captures that palette after asynchronous artwork settlement so the scene and footer agree. Focused tests cover text/accent contrast, theme resolution/storage/OS events and identical renderer placement/hit targets under both palettes. Desktop/mobile-width visual checks remain separate from those unit guarantees.

## Portrait-footprint tree spacing

The accepted visible-tree presentation allocates angular room by **(portrait width × portrait height)^0.625**, using the complete selected-country Everybird size reference. This is a display-space heuristic: source topology and leaf sequence remain unchanged, and True distance keeps every dated node radius. Shared historical source tips use the maximum associated footprint once; a combined weight of `1e-4` of the recorded weight keeps unrecorded source tips in tiny positive slots for background context. Internal angles follow weighted descendant intervals. The implementation adopts the pure footprint draft, not the alternative minimum-width/count blend.

Visible portraits still stay on their displayed tip rays and use the three-pass outward packing. Full-circle weighting is stable under taxonomy visibility and background toggles; focused fans have an explicit stable angular domain. Averaged/True size can intentionally change footprint weights and angles. Hidden circles retain the separate compact sequence/color arrangement and adaptive count disk. Showing the tree restores the footprint-spaced branch presentation, rather than the former full-global-tree angular allocation. Angular distances and portrait radii do not encode evolutionary age.
