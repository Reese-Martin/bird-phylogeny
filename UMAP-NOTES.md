# Bird map: phylogenetic MDS

The **Bird map** view uses **metric MDS initialized from UMAP**, run locally in a separate browser worker. UMAP initialization uses **umap-js 1.4.0**. MDS and full sticker packing are the fixed presentation; the interface has no algorithm, placement-mode or movement-cap selectors. The tree remains the authoritative view of topology and source divergence distances. No observation records, names, countries, distances or coordinates are transmitted to another service.

## Input and fitting

For each species with source coverage, the input is its pinned source-tip mapping. Pairwise distance is the sum of the original tree's branch lengths along the connecting path: `depth(a) + depth(b) − 2 × depth(LCA(a,b))`, in the source's approximate millions-of-years units. Binary-lifting LCA queries use original branch lengths; Compact mode, taxonomic names, order/family labels, sticker appearance and geographic coordinates never enter the calculation.

Identical sets of source tips are one input concept, so current species sharing an older tip occupy exactly the same embedding anchor. Packing can give them separate decorative portrait positions without inventing a phylogenetic split. Multi-tip mappings use the arithmetic mean of all cross-tip patristic distances to another source concept. This is a disclosed aggregate dissimilarity for lumped concepts, not a new dated source tip. Species without a reliable source placement are excluded from the embedding, counted explicitly, and displayed separately in a labeled unplaced area.

The exact symmetric distance matrix is held as Float64. Exact nearest neighbors (including each point itself) are selected deterministically, breaking ties by sorted source-concept index. These neighbor indices and distances are supplied through `setPrecomputedKNN`; species index vectors are only matrix lookup keys. We do **not** run Euclidean UMAP on rows of a distance matrix, which would measure a different dissimilarity. Input distances are divided by their common maximum for numerical conditioning; this does not change their relative values or neighbor rankings.

The UMAP initialization uses two output dimensions, **15 neighbors** (reduced to `n−1` for smaller inputs), **min_dist 0.15**, spread 1, **300 epochs**, and a deterministic Mulberry32 random generator with **seed 42**. The JS implementation starts from random coordinates rather than the Python implementation's usual spectral initialization.

The method then refines that UMAP arrangement with **uniform metric MDS (SMACOF)** against the same complete patristic-distance matrix. Its objective is the sum of squared differences between target evolutionary distances and 2D Euclidean distances; no order/family labels or image features enter the fit. Each distinct source placement has equal weight. This is the UMAP-initialized, uniform variant evaluated in the local experiments, rather than the separately tested order-balanced MDS variant; the test collection had one distinct placement per species. UMAP coordinates are divided by their flattened coordinate standard deviation, scaled by 0.3 and centered, matching the experiment protocol. MDS runs for at most **1,000 iterations** and stops when the stress decrement divided by the sum of squared embedded pair distances is below **1e−7**. Metadata records iteration count, initial/final stress, normalized stress and convergence state. It is implemented in the worker without adding a Python or scikit-learn runtime to the app.

Code ordering is canonical. Selecting an order, family or genus highlights its members and count within the complete current-country arrangement. Other country birds remain visible but dimmed. A group change does not filter the canvas membership, recompute or repack coordinates, or zoom the camera; the species list can still show the selected group's members. Groups with no recorded birds are omitted from the picker at every rank. Changing the country computes a separate fit. Cache identity includes the collection, country and algorithm version. Changing sticker size does not recompute the embedding, but does recompute decorative packing.

Zero, one or two source concepts use a clearly reported simple display rather than pretending to run UMAP or MDS. An input with three or more concepts whose source distances are all zero is reported as degenerate and placed at a common origin. The result metadata records which method actually ran.

## Cost and cancellation

Exact pairwise input is quadratic, and MDS adds repeated quadratic distance/stress updates. The experimental view has a hard limit of **3,000 distinct source placements** (a maximum 72 MB distance matrix, plus neighbor graph and optimizer storage). It never silently samples or truncates. Larger collections receive an explanation and can use a smaller country collection or the tree. The worker reports distance, neighbor, UMAP and MDS progress; cancellation terminates it immediately. The main thread remains free for ordinary interaction. Up to four completed method/collection/country fits are cached in memory per source tree; no embedding is saved into the personal collection or exported backup.

## Interpretation

Nearby points can help explore phylogenetic neighborhoods. MDS explicitly attempts to improve global distance agreement, but a flat 2D map cannot preserve all distances in a large branching tree. Its axes and orientation have no biological meaning; individual gaps, empty space and visual cluster size remain distorted approximations rather than calibrated dates. UMAP prioritizes local neighborhoods and can also distort densities and introduce apparent separations. Species drawn in different clusters do not establish new taxonomic groups, and no clustering algorithm or new biological classification is applied.

## Sticker sizing and packing

Bird map always uses **full packing**: a largest-first outward search separates illustrations using a spatial broad phase and separate conservative 24-cell collision masks, retaining transparent concavities. Individual movement has no displacement cap. This can materially rearrange the visible neighborhoods from the fitted MDS coordinates; the displayed sticker distances therefore include packing distortion as well as the approximation inherent in MDS. The worker reports maximum normalized displacement and a modeled overlap invariant. Independent occupied-mask and native-alpha checks verify tested layouts; the full-packing zero counter alone is not a pixel-level scene audit.

Every mapped species retains its raw and uniformly transformed embedding anchors. The anchor transformation is calculated from the original measured geometry before applying the common **Sticker size** slider (**20–100%**). That slider scales every portrait equally, preserving relative mass/shape sizing. The fitted anchors remain fixed; changing size can change the separately packed portrait positions. Group highlights retain both the fit and packing.

All portraits remain in the view's collection, including dimmed birds outside a selected taxonomic group. There is no crowding-based sampling or deletion. The species list remains available for selection. Selected and hovered portraits draw above other birds, hit testing follows the visible alpha masks from topmost to bottommost, and a dashed leader connects a moved portrait to its original anchor. These cues expose decorative movement without changing the phylogenetic coordinates. The interface, accessible canvas description and PNG export disclose full packing and the common size factor.

Everybird's mass-based size modes and silhouette-area correction are reproduced from the pinned reference. **Averaged size** uses mass to the power 0.2, corresponding to Everybird's “Evened out” mode; **True size** uses the cube root. The whole loaded country/collection supplies the lightest mass; taxonomic selections retain that reference and arrangement. Switching size mode changes relative illustration geometry and packing while retaining the same raw embedding fit. Zoom scales the world-space illustrations uniformly. Overview fitting includes their complete extents and the separate unplaced area. The image scheduler requests all portraits intersecting the viewport, even when their count exceeds its ordinary retention limit; wanted images remain protected until hidden. Offscreen culling during pan/zoom changes drawing only, not membership.

Collision occupancy is now separate from those unchanged Everybird sizing/hit masks. `public/data/sticker-collision-masks.json` conservatively unions all nonzero-alpha pixels of both local 128/384 px assets on the same rounded-aspect grid, with a one-source-pixel guard. Full packing uses that larger footprint; it can increase the decorative anchor scale and overall packed extent. The original MDS coordinates, mass/shape dimensions and common-size ratios are unchanged. Missing collision metadata uses a full rectangular tile. Regenerate with `.\npm.cmd run artwork:collisions`; source pins, image hashes and capture settings are in `data/sticker-collision-masks-source.json`.

Count information occupies a protected canvas header rather than covering the birds. Name boxes must fit in whitespace outside image tiles; otherwise selection remains available in the separate details panel. Leader segments skip image tiles, group tints are drawn behind all artwork, and active borders are omitted where their tile would intersect another portrait's bounds. The optional color arrangement belongs only to the birds-only radial presentation; it never enters this MDS pipeline.
