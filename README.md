# phyloBirds — personal bird phylogeny

A local React/TypeScript explorer of the real **11,167-tip Aves 1.7 / Clements 2025** tree, with browser-only eBird CSV import, country-specific personal trees, an official eBird/Clements 2026 crosswalk covering **all 11,201 current species**, and local bird illustrations. Public hosting is deferred until local review, as specified in [plan.md](<plan.md>).

Track the remaining GitHub Pages setup and personal-site integration in the [deployment checklist](DEPLOYMENT-PLAN.md).

## Start on this computer

Double-click **`Start-Everybird.cmd`**, keep its console window open, and visit **http://127.0.0.1:5173/**. Press **Ctrl+C in that console** to stop the server.

The launcher now serves the production app, with compressed text assets and durable caching for versioned stickers/sheets. It builds once on the first launch or after source/catalog changes (about one or two minutes on this computer), then reuses the unchanged build. If an older development server already occupies port 5173, close its console with Ctrl+C before launching; the launcher leaves running servers alone. The development server also has the improved sticker middleware, so refreshing an existing session uses the new image loader immediately.

The launcher installs dependencies if they are missing. Node 24+ is required; it uses Node on PATH or the Codex-provided Node runtime already present on this computer. The checkout-local `npm.cmd` wrapper bootstraps npm 12.2.3 from the official npm registry when needed. It does not change system PATH, npm, or R installations.

From PowerShell in this folder:

```powershell
.\npm.cmd ci
.\npm.cmd start
```

With a normal Node/npm installation, `npm ci` and `npm start` work too. For development, the plan's `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort` command remains available. The prepared data and artwork are committed to the project; normal startup needs neither R nor source downloads. After installing dependencies, runtime requests stay on localhost.

The server binds only to `127.0.0.1`. If port 5173 is already occupied, the strict-port error leaves that other process alone; choose a known free port, for example `--port 5174`, and open the printed URL. Browser storage is scoped to the origin, including its port.

## Git and a second computer

Install Git and Node 24 or newer, clone the repository, and run these commands from the cloned project directory:

```sh
npm ci
npm test
npm run build
npm start
```

The source, prepared public datasets, all artwork tiers and sheets, fonts, and generated delivery settings belong in Git. Normal builds and startup need no R, Python, API key, or raw-source downloads. Install dependencies independently on each computer with `npm ci`; do not copy `node_modules`. The `.cmd` shortcuts are for Windows; the commands above also work on macOS and Linux.

The repository's `.gitattributes` disables Git line-ending conversion because generated datasets and their preparation scripts have exact SHA-256 provenance records. Preserve the checked-in bytes when transferring the project between operating systems. `.gitignore` excludes `personal/`, `data/raw/`, build output, installed dependencies, local tools, verification results, and credential files. Personal CSVs and collection backups do not belong in the repository. Browser collections do not sync through Git; reimport your CSV or restore a collection backup on the other computer.

`npm test` runs the self-contained application and prepared-artifact checks available in a fresh checkout. Additional comparisons against the original downloaded evidence run explicitly with `npm run test:provenance`. That audit requires the pinned raw sources and normalized official workbook; see [source preparation](README-DATA.md). Missing source evidence is reported as an error rather than skipped.

Pull before starting work on either computer, then commit and push completed changes so the other computer can retrieve them. Publishing the built website through GitHub Pages is a separate configuration step.

## Explore and import

- Use **Explore / Arboretum** below the header to switch sections. The **Arboretum** shows the complete collection and country trees, plus year trees for **Growing life list** (through that year) or **Each year** (only observations in that calendar year). Its country filter combines place and time; opening a card scopes the full explorer to that selection. The explorer's Year control and **All years** action use the same summaries. Lightweight, lazy branch-only previews do not download stickers or run MDS for every card.
- Choose **Animate growth** in the Tree view or the Arboretum's Growing life list shelf to replay first-recorded species chronologically. Country views use first sightings in that country; a selected year limits the growing list through that year. The species counter beside the timeline follows playback and scrubbing. Play/pause, replay, speed, previous/next date and a scrubber are available. Birds recorded on the same day appear together, skipping dates without additions. The final dated-species layout and camera stay fixed. New branches grow continuously in the interface accent color, and portraits fade in as their branches arrive. Growth uses drawn path length for visual pacing, not evolutionary time. The Speed control changes its duration without retracting a partly drawn branch. Undated species remain outside the animation with a visible count. Checklist totals still cover the selected period; the animation shows exact first-seen membership, not daily observation totals. Reduced-motion preferences start playback paused. Choose **Play** to start. Pausing or scrubbing shows a completed date frame; background tabs and dialogs pause playback. **Export frame** downloads a paused PNG, including its date and source notes.
- New CSV imports retain normalized annual and cumulative summaries, including distinct checklist counts for the selected period and country. Missing, invalid and 1900 placeholder dates remain in all-time trees but cannot establish membership in a dated year. All year views apply the current taxonomy. Older backups remain usable; without annual history they offer first-seen cumulative membership, with full-export checklist totals clearly labeled. Reimport the full CSV for exact annual and cumulative period totals.

- The opening collection has **24 real species with invented observation history**. The sample is labeled throughout the interface and in PNG exports. By default, the canvas draws only the source branches needed to connect recorded birds to the root. **Show other branches** restores the surrounding source tree when desired.
- Pan by dragging and zoom by wheel/pinch or the buttons. **All birds** resets the view and taxonomy within the selected country; **All countries** clears the country filter. A focused canvas also supports arrow-key pan, `+`/`−`, and `Home`. **Collection** shows or hides the species panel.
- The header's Sun/Moon button switches **Light / Dark** appearance. The initial setting follows the operating system; **Use system theme** in the collection's `•••` menu restores that behavior. Explicit choices persist on this browser/origin. If browser storage is unavailable, the choice still works for the current session. Controls, the world map, both canvases and PNG exports share the selected palette; original illustration colors are unchanged. Theme changes redraw existing plots without recomputing their layouts or moving the camera.
- Search common or scientific names. **My collection** includes unresolved records; **All species** searches the complete current species taxonomy. Press `/` to focus search, then Enter/ArrowDown to select its first result. The list, detail panel and previous/next controls provide keyboard access to the same taxon selection.
- The single **Phylogenetic level** picker drills from **order → family → genus**, showing recorded-species counts and omitting groups with no recorded birds at every rank. The adjacent up-level arrow returns one rank; **All orders** or **All birds** clears the taxonomic selection. In Tree, selections filter the displayed group and optional background branches; with branches visible, an order can open as a **240° fan**. In Bird map, group members retain their colors while other country birds remain visible in gray, without group boxes. Nonmembers remain gray during hover or individual selection; the details card retains the original illustration. Group changes retain the complete country's layout and camera position.
- The visible tree now uses the accepted **portrait-footprint** angular arrangement: larger portrait footprints receive more angular room, with weight proportional to tile area raised to **0.625**. The reference is the complete selected-country collection, and internal branch angles follow the weighted descendant intervals. Source-tip sequence and topology are retained; **True distance** retains every dated node radius. A shared historical source tip receives one angular weight, using the largest mapped portrait footprint, and unrecorded source tips retain tiny positive slots for background context. Full-circle angles do not change when taxonomy visibility or background branches are toggled; group fans use a stable angular domain. Switching relative size mode can change footprint spacing intentionally. This is pure footprint weighting, not the minimum-width hybrid draft.
- Birds remain upright outside the branches, keep their displayed tip angle and move outward as needed. Three deterministic packing passes compare both angular directions and largest-first insertion, choosing the smallest maximum portrait radius. Portraits retain their dimensions and image proportions; rectangular bounds avoid each other and the branches. Shortening the longest tail can move some other birds farther outward. A species mapped to several older source tips can appear at each one. Portrait radius is decorative spacing, not an evolutionary distance; the true-distance scale applies to the branches. Selecting or hovering a bird reveals its source-tip connection. Reset fits the complete portrait halo; zoom for detail. This is an app-specific interpretation of the stacked radial portraits in the supplied reference figure.
- In **Phylogenetic** order, hiding **Show tree** closes unused angular gaps into a compact bird circle while retaining source-tip sequence. Both birds-only styles give larger portrait footprints more angular room without resizing the images. Portraits pack around a protected species count: its center radius is at least 0.36 world units, or 12% of the provisional maximum portrait extent when larger, rather than reserving the tree's fixed 1.14 radius. Count text scales within that disk. These angles and radii are decorative. Showing the tree again restores its footprint-spaced branch presentation and the selected radial branch-distance mode; the camera refits the changed arrangement. Branch-length controls appear only when branches are shown.
- **Bird order → Color within orders** opens a separate birds-only arrangement. Orders retain their source sequence; birds within each order are sorted by the predominant color measured from their illustrations. Each species appears once, including birds without source placement. Choosing **Phylogenetic** returns to source-tip sequence; enabling **Show tree** also returns to phylogenetic order and the footprint-spaced branch presentation. Color arrangement changes neither the source tree nor MDS coordinates. [COLOR-NOTES.md](<COLOR-NOTES.md>) explains sampling, neutral colors and reproducibility.
- Navigation controls and the selected-species panel sit outside the drawing area; on phones, details flow below the plot. Imports open the whole collection without automatically selecting a bird. Canvas labels use free whitespace, source leaders avoid image tiles, and selected outlines stay within their own tiles.
- Choose **True distance** for the published radial branch distances, approximate date rings and calibrated time scale. **Compact** shortens long branches for easier exploration. Compact is explicitly labeled **not to scale** and has no divergence-time scale. Both use footprint-spaced angles and preserve source topology; the order fan changes the angular presentation without inventing split dates. Angular separation and portrait radius are display spacing, not evolutionary distances.
- Switch from **Tree** to **Bird map** to explore a 2D projection of source-tree patristic distances. Seeded UMAP supplies the starting arrangement, then metric MDS refines agreement with the complete original distance matrix. Country changes compute a separate fit. Taxonomic selections highlight members within that fit without filtering out other birds, recomputing coordinates or zooming to the group. Birds without source placement appear in a separate labeled area. MDS attempts to improve global spacing, but the map is an approximation rather than an exact reconstruction of every tree distance or a calibrated time plot.
- Bird map uses **full packing** to separate the stickers. This decorative step can move portraits without a displacement cap and materially change the visible neighborhoods from their fitted MDS positions. All portraits remain in the collection, and the overview fits their complete extents. Hover or use the species list for names and details; selected birds draw above their neighbors, and moved birds show a dashed leader to their original fitted position.
- The Bird map's **central species count** occupies a protected space in its packing. Birds, names and source leaders stay clear of the counter; it moves with the map during pan/zoom. A selected taxonomic group adds its highlighted count without moving birds. The count includes valid species without source placement and appears in PNG exports. The former top count badge is removed; source MDS coordinates and phylogenetic distances are unchanged.
- Map collision checking uses a separate conservative union of all **32/64/128/384 px** artwork tiers' native alpha footprints, including a one-source-pixel guard per tier. Original Everybird masks remain the sizing and hit-testing reference. The protected count strip cannot cover artwork, and floating names are shown only where they fit without covering birds. Missing collision metadata uses a full-image rectangle.
- **Averaged size / True size** follows Everybird's body-mass and painted-area formula in both views. Averaged size uses exponent 0.2, corresponding to Everybird's “Evened out” mode; True size uses 1/3. Both correct for measured alpha-silhouette area and retain the loaded collection's size reference across taxonomic selections. The full local library's mass, aspect, 24-cell masks and occupied area are captured in `public/data/sticker-geometry.json`, with pinned sources and hashes in `data/sticker-geometry-source.json`. See [STICKER-GEOMETRY-NOTES.md](<STICKER-GEOMETRY-NOTES.md>) for the exact capture procedure and comparison against Everybird.
- Bird map uses a fixed common sticker scale; the former Sticker size slider is removed. **Averaged size / True size** still controls relative body sizes. Switching relative size mode retains the same embedding fit but recomputes decorative packing, so displayed portrait positions can change. The UMAP initialization remains 15 neighbors, minimum distance 0.15, 300 epochs and seed 42. Metric MDS uses at most 1,000 iterations with convergence tolerance 1e−7. The original tree and phylogenetic distances are unchanged.
- UMAP initialization and MDS refinement run locally in a cancellable worker. Species without source placement are counted rather than assigned invented coordinates; shared source concepts share a point. The exact distance matrix supports up to **3,000 distinct source placements** per country/collection, with an explicit explanation above that limit and no silent sampling. Progress and result metadata distinguish initialization, refinement and small/degenerate fallbacks. Method, source mapping and limitations are documented in [UMAP-NOTES.md](<UMAP-NOTES.md>).
- Completed fits and sticker layouts are cached automatically on this browser/device in IndexedDB, bounded to **24 entries / 16 MiB of serialized payload**. SHA-256 keys include actual source content, mappings, algorithms and layout settings; results are validated before reuse. Unavailable, full or corrupt storage falls back to computation. The cache stores derived coordinates, species identifiers, small layout geometry and metadata, with no raw observations or distance matrices. It is separate from explicitly saving the collection and is not included in collection backups.
- Open the map at the bottom right of the plot and choose a shaded country or a country in the searchable list. The app builds its tree from species recorded in that country. Taxonomy choices then drill into that country collection. **All countries** restores the combined collection. Tiny territories without a separate map outline remain selectable in the list. The local Natural Earth map supports pan, zoom and keyboard selection.
- Species cards show earliest precise recorded date and distinct checklist count for the current country or combined collection. Their Order/Family/Genus links use the same drill-down. Tree group views fit the mapped recorded members without claiming monophyly from partial coverage; Bird map highlights groups within the full country arrangement. Selecting an unrecorded bird explicitly shows its ancestry as selection context.
- Use **Import eBird data**, follow the link to [Download My Data](https://ebird.org/downloadMyData), and select the full `MyEBirdData.csv`. Extract ZIP exports first. The optional quick life-list format is outside this release.
- Review the reconciliation report. Import replaces the session collection **only after success**. Cancellation or failure keeps the previous collection. The displayed total counts resolved species recorded in the export; unresolved reports remain inspectable separately. It does not claim to reproduce eBird's eligibility-based official life list.
- `X` counts as presence; zero, invalid counts and non-species identifications have explicit report dispositions. Identifiable groups roll up to their parent species. January 1, 1900 is an unspecified historical date, not a precise first record.
- **Save on device** explicitly saves normalized species, country and year aggregates in IndexedDB, including those needed to recreate the Arboretum. A saved collection is restored on startup. The `•••` menu offers backup, restore, sample loading, and **Clear collection, saved copy & layouts**. Clearing removes the session collection, saved collection and both memory/persistent layout caches; a browser storage failure is reported. Loading a different collection does not overwrite the saved copy until you save it. Older saved collections/backups without country/year summaries remain usable for the combined tree; reimport the full CSV to enable the full Arboretum.
- **Export view** downloads a PNG with the current visualization, layout/country context, dataset version, source URLs and illustration/license credits. True-distance exports retain the matching branch time scale when the tree is shown; radial stacks disclose their decorative portrait radii. Compact and Bird map exports disclose their approximate/unscaled presentation. Bird map exports identify MDS initialized from UMAP, full packing and the relative size mode. Group highlights and visible selected labels/stickers are included, without exporting checklist identifiers or exact locations.

Country summaries retain only country codes/names and normalized species aggregates, with distinct country checklist counts and earliest valid dates. A species recorded in several countries appears in each country's tree but once in the combined species total. Country assignment uses explicit country fields or the country prefix of an eBird state/province code; rows without a reliable country stay in the combined collection and are counted in the report.

Observation coordinates, exact location names, comments and checklist IDs are not included in saved collections or image exports. Submission IDs are used transiently for deduplication and discarded. The map displays country totals rather than observation points. There are no analytics, remote map tiles, remote runtime fonts, remote artwork requests, accounts, or uploads. Selecting external source/help links deliberately opens those external sites.

## Sources and current limits

See [README-DATA.md](<README-DATA.md>), [data/coverage-report.md](<data/coverage-report.md>), and [README-PERFORMANCE.md](<README-PERFORMANCE.md>) for reproducibility, complete coverage counts, source licenses, and observed performance.

- The dated source is pinned, hashed, and independently audited with **R 4.5.0, ape 5.8-1, and authors' clootl 0.1.5**. All 11,167 tips, rooted clades, leaf order, and branch lengths agree. The root is approximately **99 Ma**, with a source interval of **72–133 Ma**. Dates and source support remain estimates.
- The supplied official eBird/Clements 2026 workbook is integrated for **all 11,201 current species**. Official concept IDs establish **11,121 direct same-ID matches** (10,928 exact and 193 renamed), independently of artwork. Reviewed annual changes place another **70 species within broader source tips** and **4 species across their narrower source tips**. In total **11,195 species are mapped**, with **6 genuine source-placement gaps** kept explicit. Every entry retains worksheet-row and annual-change evidence; names alone never force a placement. Willet remains a verified split regression, and lumps preserve every relevant older tip. The original source topology and dates remain intact.
- **11,027 species** have local AI-generated artwork at **32, 64, 128 and 384 px**; all images available for the pinned current taxonomy are bundled. The two overview tiers are deterministic lossless derivatives of the pinned 384 px images, retaining their full transparent canvas. There are 174 global artwork gaps, independent of source-tree coverage. Missing or failed images use a consistent fallback. AI illustrations come from huashu-bird-sticker, resized by Everybird under CC BY 4.0.
- Everybird inspired the light appearance’s paper, ink and deep red palette. phyloBirds pairs locally served Fraunces and Source Sans 3 with charcoal surfaces, warm light ink and a coral accent in dark appearance. The design reference, theme behavior and font licenses are recorded in [STYLE-NOTES.md](<STYLE-NOTES.md>).
- Stickers are decoded through a six-request queue. Resolution follows displayed physical size across **32/64/128/384 px**, with DPR capped at 2 and hysteresis to avoid repeated tier switching. A ready tier stays visible while its replacement loads. The cache uses a **32 MiB estimated decoded-byte budget** plus a soft 512-entry target; every wanted image stays protected, so a complete overview can exceed either target. Unneeded resolution copies and grayscale variants are released. Metrics estimate native RGBA/canvas bytes, not total browser/GPU RAM. Artwork availability and source-tree coverage remain independent.
- The country map uses 177 locally prepared Natural Earth outlines, pinned and hashed under a public-domain license. Its projection, antimeridian handling, country-code joins and small-territory limitations are documented in [MAP-NOTES.md](<MAP-NOTES.md>).
- This is the local implementation and review build. The provided personal export, including country summaries, has been verified locally; user-specific results remain in ignored files. Its six former placement gaps resolve through the official concept IDs. Public hosting remains a separate review item. Cornell taxonomy redistribution terms must be reviewed before public release.

Source regeneration uses `.\npm.cmd run data:fetch`, `.\npm.cmd run taxonomy:import` and `.\npm.cmd run data:build`. The import wrapper selects the bundled Python or Python 3 with openpyxl 3.1.5 and runs the read-only `scripts/import-clements2026.py` extractor. Original-workbook, extractor and normalized-data hashes are retained in `data/clements2026-source.json`. Run the optional independent R audit again after tree changes. The R audit details and exact source pins are in [README-DATA.md](<README-DATA.md>). The original plan is preserved unchanged.

Regenerate the small image tiers with `.\npm.cmd run artwork:overviews`, or verify their exact repeatability with `.\npm.cmd run artwork:overviews -- --verify-only`. Then run `.\npm.cmd run artwork:collisions` to union all four tiers. [Overview provenance](<data/sticker-overviews-source.json>) records per-file hashes, resizing settings and complete alpha/aspect checks; [collision provenance](<data/sticker-collision-masks-source.json>) records all 44,108 source-tier masks. For the tested 700 birds, the 32 px tier totals **871,640 encoded bytes / 2,267,392 native RGBA bytes**, versus **3,026,284 / 36,265,984 bytes** at 128 px. These are asset sums, not process-memory measurements. See [PERFORMANCE-AUDIT.md](<PERFORMANCE-AUDIT.md>) for limits and remaining work.

Regenerate overview delivery sheets after changing the artwork with `.\npm.cmd run artwork:sheets`; `-- --verify-only` checks exact repeatability. The 1,380 lossless 16-bird sheets cover all 11,027 species at 32/64px, preserving each original image's dimensions, alpha and visible RGB. The loader chooses sheets only when at least two wanted birds share one and its encoded size stays within an 8× per-group transfer allowance; sparse groups use individual files. This trades some neighboring artwork bytes for fewer requests. Only requested crops enter the main image cache; a separate 8 MiB sheet cache releases unused decoded sheets. A 32px overview appears before sharper artwork is requested, and remains visible during upgrades. HTTP and explicit-decode scheduling are separate, with finite decode/crop fallback deadlines. [Sheet provenance](<data/sticker-sheets-source.json>) pins every source and generated sheet. No observation data enters these public assets.

Regenerate the independent local map asset with `node scripts/fetch-map.mjs`; its pin and output hashes are in `data/map-source.json`.

## Synchronized country growth

During **Animate growth**, choose **All countries together** to watch the combined life list alongside each country's own tree. **Single tree** keeps the original explorer and its selected country available. Click a country tree to open its single-tree animation. The switch pauses on the latest sighting date at or before the shared date. The comparison uses the current cumulative year cutoff and includes country-only addition dates: a bird can grow a country's tree even if it was already on the combined list. Each panel keeps its own final portrait packing and camera. Use Single tree to inspect birds; **Export main frame** exports the combined tree's paused PNG.

Playback is paced by the number of additions on each date. Quiet dates pass quickly; large bursts get more drawing time and still grow faster than quiet dates. Same-day records remain grouped, without invented within-day sighting times. At 1×, one addition gets about **210 ms**, while forty additions get about **1.31 s**. In the country comparison, pacing considers activity across all panels. The provided collection has **170** combined-list dates and **181** dates when country additions are included. Blank calendar periods are skipped.

Country panels share one sticker cache and delivery queue. The responsive comparison fits several columns on larger screens and stacks into a scrolling list on phones; all panels follow the same date and animation clock.

## Export an animation

From **Animate growth**, choose **Export animation**. Under **Trees to export**, choose **Life list only** for a single tree or **Life list + country trees** to include every country, including cards below the current scroll position. The export uses the current Light/Dark appearance, bird-size option, branch-length mode and cumulative year cutoff. Dates and counts appear with the trees, along with layout notes and source credits.

- **Video** uses the browser's supported **MP4 or WebM** format at **24 frames per second**. Keep the tab visible while it records.
- **Animated GIF** uses **12 frames per second** and a **256-color palette**. GIFs loop and can show fewer colors than video.
- Choose **15, 30 or 60 seconds**. Activity-based pacing gives larger additions more time while keeping same-day birds grouped. The selected duration includes a brief opening and a hold on the completed trees.
- **Standard / Large** selects **1,280 / 1,920 px** width for video or **800 / 960 px** for GIF. The grid height fits all trees; unusually large country sets may use a wider bounded canvas. The result reports its actual dimensions and file size.

Choose **Create animation** to prepare the illustrations and encode the file. Progress is shown, and **Cancel export** or closing the dialog stops the work without changing the collection. The completed file downloads automatically; **Download** saves it again if needed. Everything is generated locally on this device, without screen sharing or uploading the eBird data.

GIF encoding uses the bundled **gifenc 1.0.3**, under the MIT license. Its notice is included in [public/licenses/gifenc-LICENSE.txt](<public/licenses/gifenc-LICENSE.txt>).
